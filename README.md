# Pharmacy Medication Tracking System

This project is a simple console-based Java application that simulates a pharmacy medication tracking system.

The system allows users to manage:
- doctors
- patients
- medications
- prescriptions

The goal of the project is to demonstrate Object-Oriented Programming concepts such as inheritance, encapsulation, and relationships between classes.

## Main Features

- Add patients, doctors, and medications
- Process prescriptions
- Generate system reports
- Check expired medications
- Restock medications
- View prescriptions by doctor
- View prescriptions by patient
- Generate summary of prescriptions from the past year

## Technologies Used

- Java
- Java Collections (ArrayList)
- Java Time API (LocalDate)

## Run Instructions

Compile the project:

javac src/medicationtracking/*.java

Run the program:

java -cp src medicationtracking.EmptyMenu
